## 🚀 Getting Started

### Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/x0t68/x0t68.github.io.git
   cd x0t68.github.io
   ```

2. **Open in browser**:
   - Simply open `index.html` in your web browser
   - Or use a local server for better results:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

3. **View online**:
   - Visit: `https://x0t68.github.io`

## 🔧 Customization

### Adding New Projects

Edit `projects.json` and add a new project object:

```json
{
  "id": 6,
  "name": "Your Project Name",
  "description": "Project description",
  "technologies": ["Kotlin", "Jetpack Compose"],
  "image": "🎯",
  "github": "https://github.com/yourusername/yourproject",
  "status": "Active"
}
```

### Updating Contact Information

Edit the contact links in `index.html`:
- Update email address
- Update LinkedIn profile URL
- Add/remove social media links

### Changing Colors

Modify CSS variables in `style.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    /* ... other variables ... */
}
```
